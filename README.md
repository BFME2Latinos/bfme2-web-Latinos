# BFME II — Portal

Página estática preparada para GitHub Pages. El HTML conserva el contenido y diseño; las imágenes están separadas en `assets/images/`.

## Publicar en GitHub Pages
1. Sube todo el contenido de esta carpeta a un repositorio.
2. En **Settings → Pages**, selecciona la rama y la carpeta raíz `/ (root)`.
3. Guarda y espera la publicación del sitio.
